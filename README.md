# Quiz Game

An interactive, browser-based quiz application built with **HTML, CSS, and JavaScript**. Test your knowledge across different topics with a randomized set of questions in every attempt.

🌐 **Live Demo:** https://arjunadevweb.github.io/quiz_game.project/

## Features

- **50-question question bank** covering topics such as science, geography, mathematics, history, technology, art, and literature.
- **25 questions per attempt**, selected randomly from the question bank.
- Randomized question order and answer options.
- Five answer choices for each question.
- 25-minute quiz timer.
- Live score and progress tracking.
- Question navigator to move between questions.
- Mark questions for review.
- Clear an answer and change it before submitting.
- Submit confirmation and quiz result screen.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

You can run the project locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/ArjunaDEVWEB/quiz_game.project.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No package installation or build step is required.

## How It Works

The app keeps a bank of 50 questions in JavaScript. At the start of an attempt, it shuffles the question bank and uses 25 questions for that quiz. Answer options are also shuffled while keeping the correct answer associated with its option.
